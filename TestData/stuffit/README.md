# StuffIt archive samples #

There are two types of ".sit" archives, associated with StuffIt v1.5 and
StuffIt v5.  The format is noted in the filenames.

`simple_15.sit`: contains three files hand-crafted to exercise the three
compression methods supported by StuffIt v1.5.1.

`simple_45.sit.bin`: a single file compressed with StuffIt Deluxe 4.5.
Has an archive comment and is wrapped with MacBinary.
